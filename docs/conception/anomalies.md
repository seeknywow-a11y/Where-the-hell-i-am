# Pistes d'anomalies

Une anomalie est un écart vérifiable dans le colis, le poste de tri ou le hangar visible. La majorité des propositions reposent sur un détail discret qui devient clair quand on regarde attentivement ou qu'on rapproche deux informations. Quelques écarts plus visibles et fantaisistes donnent de la variété sans transformer l'ambiance en horreur. Ces exemples forment une réserve de conception, pas une liste définitive.

Le [tableau de suivi par poste](suivi-anomalies.md) fixe la progression de difficulté et reçoit les anomalies retenues. Une même anomalie ne peut apparaître qu'une fois par tentative complète. Au poste 1, aucun objet fixe ne change de place : leur position fournit une référence fiable pour la suite. Les anomalies retenues sont réparties entre les murs [est](anomalies-mur-est.md), [nord](anomalies-mur-nord.md), [ouest](anomalies-mur-ouest.md), [sud](anomalies-mur-sud.md) et le [décor général](anomalies-decor-general.md).

| Type | Exemple | Référence nécessaire |
| --- | --- | --- |
| Visuel, colis | Le code de couleur de l'étiquette ne correspond pas au bac indiqué. | Légende des couleurs visible au poste. |
| Visuel, colis | Une étiquette de contrôle manque sur un côté normalement marqué. | Modèle de référence affiché dans le poste. |
| Visuel, poste | Le panneau d'un casier a été échangé avec celui d'à côté. | Numérotation régulière et lisible. |
| Visuel, poste | Un voyant du mécanisme de transfert est allumé alors que la table est à l'arrêt. | Fonction des voyants expliquée avant ce cas. |
| Déduction, adresse | La ville inscrite sur le colis ne correspond pas au code postal. | Annuaire ou tableau de routage consultable. |
| Déduction, registre | Le numéro de suivi sur le registre diffère d'un chiffre de celui du colis. | Deux inscriptions assez grandes pour être comparées. |
| Déduction, poids | Le poids relevé dépasse la plage autorisée pour le bac indiqué. | Plages de poids affichées près de la balance. |
| Déduction, parcours | Le registre marque le passage au poste suivant avant le poste actuel. | Ordre des huit postes établi clairement. |
| Mixte | Une flèche au sol conduit à un casier qui porte un autre code de destination. | Plan de circulation et codes visibles simultanément. |

## Équité des énigmes

- Rendre une référence stable accessible dans le poste pour chaque règle à vérifier, sans tutoriel séparé.
- La subtilité vient du sens du détail ou de la comparaison à faire, pas d'une taille minuscule, d'un code illisible ou de connaissances postales réelles.
- Prévoir des aides de comparaison sur place ; la mémoire seule ne doit pas être le défi principal.
- Une seule anomalie décisive au maximum par poste. Un poste normal ne doit pas contenir de détail ambigu qui ressemble à une erreur.
- Après un **CONTRÔLE INVALIDE** correct, le bras mécanique échange le colis contre une version conforme du même envoi. Si l'écart se trouvait dans le poste, le décor revient à son état normal après le départ du joueur.
- Une erreur de réponse ramène automatiquement la table, le colis et le joueur au poste 1, sans révéler la bonne réponse. Le bras mécanique échange alors le colis pour la tentative suivante. Les indices doivent rester assez clairs pour permettre au joueur de comprendre son erreur lors d'une autre tentative.
- Le numéro, le code-barres, l'étiquette et le nom peuvent changer avec chaque nouveau colis. Leur simple différence d'une tentative à l'autre n'est jamais une anomalie ; seule une contradiction vérifiable dans le contexte du colis actuel l'est.
