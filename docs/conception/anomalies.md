# Anomalies retenues

Une anomalie est un écart vérifiable dans le colis, le poste de tri ou le hangar visible. Les **66 anomalies retenues** sont décrites dans les listes par mur [est](anomalies-mur-est.md), [nord](anomalies-mur-nord.md), [ouest](anomalies-mur-ouest.md), [sud](anomalies-mur-sud.md) et dans le [décor général](anomalies-decor-general.md). Le [tableau de suivi](suivi-anomalies.md) rassemble leurs identifiants et leurs postes admissibles.

L'état normal du poste se déduit en retirant ces écarts de l'[agencement de référence](poste-type.md). La majorité des anomalies peuvent être tirées à n'importe lequel des huit postes. Les changements de place commencent au poste 2, une fois la disposition normale vue ; les anomalies qui requièrent une porte ou un panneau absent à une extrémité de la ligne ont aussi une plage réduite. Une éventuelle progression de difficulté jouera sur les probabilités de tirage, sans changer ces plages.

## Équité des énigmes

- Rendre une référence stable accessible dans le poste pour chaque règle à vérifier, sans tutoriel séparé.
- La subtilité vient du sens du détail ou de la comparaison à faire, pas d'une taille minuscule, d'un code illisible ou de connaissances postales réelles.
- Prévoir des aides de comparaison sur place ; la mémoire seule ne doit pas être le défi principal, sauf pour reconnaître les déplacements autorisés à partir du poste 2.
- Une seule anomalie décisive au maximum par poste. Un poste normal ne doit pas contenir de détail ambigu qui ressemble à une erreur.
- Après un **CONTRÔLE INVALIDE** correct, le bras mécanique échange le colis contre une version conforme du même envoi. Si l'écart se trouvait dans le poste, le décor revient à son état normal après le départ du joueur.
- Une erreur de réponse ramène automatiquement la table, le colis et le joueur au poste 1, sans révéler la bonne réponse. Le bras mécanique échange alors le colis pour la tentative suivante. Les indices doivent rester assez clairs pour permettre au joueur de comprendre son erreur lors d'une autre tentative.
- Le numéro, le code-barres, l'étiquette et le nom peuvent changer avec chaque nouveau colis. Leur simple différence d'une tentative à l'autre n'est jamais une anomalie ; seule une contradiction vérifiable dans le contexte du colis actuel l'est.
