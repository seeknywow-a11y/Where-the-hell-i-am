# Propositions d'anomalies — mur est

Les anomalies E01 à E13 sont retenues. Leur poste exact reste à choisir dans la plage indiquée. Le changement se produit uniquement sur le mur est : tableau d'informations, porte vers le poste suivant, signalétique ou fenêtre latérale floutée. Le colis et les autres murs fournissent parfois la référence de comparaison, mais restent dans leur état normal pour cette anomalie.

Les numéros de poste indiquent où l'idée pourrait être utilisée, pas une affectation définitive. Au poste 1, aucune pièce fixe du décor ne change de place. Une seule anomalie peut être active dans un poste, et un même identifiant ne peut pas revenir deux fois pendant la même tentative.

Pour les propositions qui utilisent des données de suivi, le tableau est pourrait recevoir une fiche amovible liée au colis en cours, à côté d'un plan de routage permanent. Cette composition reste une piste, pas un élément de décor validé.

Les numéros de poste, heures, destinations et codes ci-dessous servent d'exemples ; ils seront adaptés au poste retenu.

| --- | --- | --- | --- | --- |

| E05 | 2–4 | Deux petites plaques magnétiques de destination ont échangé leurs emplacements sur le tableau. | Les codes gravés sous les plaques ne correspondent plus aux plaques posées dessus ; le poste 1 montre leur disposition normale. | Retenue, poste à fixer |

| E10 | 4–8 | Le plan du mur est porte la version **TRI-04**, alors que l'ordinateur du bureau ou une note de service indique que la version en vigueur est **TRI-05**. | Comparer les numéros de version ; l'ancien plan est encore présenté comme actif. | Retenue, poste à fixer |
| E11 | 4–8 | Une ligne du tableau indique « Lyon → quai B », tandis que le petit plan accolé indique « quai B → Lille » et « Lyon → quai C ». | Suivre la destination du colis dans la liste, puis vérifier le quai sur le plan du même mur. Le « quai » est un emplacement d'expédition du hangar. | Retenue, poste à fixer |
| E12 | 5–8 | La fiche du colis sur le mur est affiche le code de tri **AB-74**, alors que le colis et l'ordinateur du bureau affichent **AB-47**. | Deux chiffres sont inversés sur la fiche du mur est ; les deux autres sources concordent. | Retenue, poste à fixer |
| E13 | 5–8 | Le tableau marque le contrôle du poste actuel comme terminé alors que le joueur n'a pas encore appuyé sur un bouton. | Comparer l'état « terminé » avec le numéro du poste et l'état de la table avant décision. | Retenue, poste à fixer |

Pour chaque idée retenue, il faudra préciser l'état normal exact, la forme visuelle de l'écart et le poste assigné dans le [tableau de suivi](suivi-anomalies.md). Les indices doivent rester lisibles ; la difficulté vient de la comparaison à faire.
