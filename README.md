# LE COLIS EN CIRCULATION — dossier de conception

Jeu d'observation et d'enquête dans un centre de tri postal. Une nouvelle recrue accompagne une expédition à travers huit postes identiques. À chacun, elle choisit **CONTRÔLE VALIDE** ou **CONTRÔLE INVALIDE**. Une bonne réponse fait avancer l'expédition ; après une erreur, le rail ramène automatiquement la recrue et la table au poste 1.
